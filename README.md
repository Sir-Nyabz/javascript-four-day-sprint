# JavaScript Practical Sprint – Daily Reflections

## Day 1 – JavaScript Fundamentals

### What I learned
I learned the fundamentals of JavaScript, including variables, data types, operators, functions, conditional statements and loops. I practised writing reusable functions and solving problems involving calculations, grading systems, FizzBuzz and receipt generation.

### What I found difficult
The most difficult part was understanding how functions receive parameters, process information and return results. I also found it challenging to apply conditions and loops correctly when solving practical problems.

### How I solved it
I broke each problem into smaller steps and tested my code with different input values. I used `console.log()` to check the results and identify errors. I also practised tracing how values changed as the program executed. This helped me understand how functions, conditions and loops work together.

### Key takeaway
I learned that writing JavaScript requires understanding the problem first, breaking it into smaller tasks and testing the solution before considering it complete.

---

## Day 2 – Arrays, Objects and Object-Oriented Programming

### What I learned
I learned how to work with arrays and objects to organise data in JavaScript. I practised using array methods such as `map()`, `filter()`, `find()`, `forEach()` and `reduce()`. I also learned about classes, constructors, methods and object-oriented programming. I applied these concepts by building a Task Manager data engine.

### What I found difficult
The most difficult concept I encountered was understanding Object-Oriented Programming, particularly how classes, constructors, methods and objects work together. I initially found it challenging to understand the `this` keyword and how the `TaskManager` class interacts with the `Task` class. I also needed more practice using array methods to manipulate and retrieve data.

### How I solved it
I solved these difficulties by breaking the code into smaller sections and testing each part independently. I first created task objects using the `Task` class and tested their methods before introducing the `TaskManager` class. When errors occurred, I checked method names, class definitions and import statements. I also used `console.log()` to inspect objects and confirm that their properties were changing correctly. Repeated practice and debugging helped me understand how the different concepts work together.

### Key takeaway
I learned how to organise related data and behaviour using classes and objects. I also gained practical experience building a reusable data management system.

## Day 4 – Promises, Async/Await, Fetch API and Capstone Project

### What I learned

I learned how JavaScript handles asynchronous operations using callbacks, Promises, async/await, and the Fetch API. I also learned how to retrieve information from external APIs and handle errors using try...catch. I applied these concepts by integrating API functionality into my Focus Board project.

### Challenges I encountered

I encountered challenges understanding how Promises work, using async/await correctly, and handling errors when retrieving information from an API. Integrating the API functionality into the existing Focus Board also required careful attention to the project structure.

### How I solved the challenges

I addressed these challenges by practising with smaller examples, examining the browser console, and testing API requests independently before integrating them into the application.

### Key takeaways

I learned that asynchronous JavaScript makes it possible to perform operations such as retrieving information from external servers without blocking the application. I also gained practical experience combining different JavaScript concepts to build a functional application.
